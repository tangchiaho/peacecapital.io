# Peace Capital Website

Official static website for **Peace Capital（和平資本）**.

- Domain: https://peacecapital.io
- Hosting: GitHub Pages
- Brand direction: **Classic Institution** (Cormorant Garamond wordmark)

## Site map

| Path | Page |
|------|------|
| `/` | Home |
| `/about/` | About |
| `/focus/` | Focus |
| `/insights/` | Insights index (articles published when confirmed) |
| `/insights/<slug>/` | Published insight articles |
| `/insights/_drafts/` | Unpublished drafts (noindex) |
| `/contact/` | Contact |
| `/brand/` | Brand comparison (draft review only) |

## Brand assets

- Live wordmark: HTML/CSS lockup in header & footer
- Files: `assets/brand/classic/` (selected) and `assets/brand/modern/` (archived comparison)
- Root favicon / apple-touch / `assets/img/og-image.png` use Classic

## Stack

- HTML / CSS / light vanilla JS
- No build step
