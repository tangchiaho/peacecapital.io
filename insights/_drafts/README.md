# Insights drafts (unpublished)

Sample or unconfirmed articles live here and are **not** linked from the public Insights index.

- `robots.txt` disallows `/insights/_drafts/`
- Each draft page should use `noindex, nofollow`

When an article is approved for publication:

1. Move `/insights/_drafts/<slug>/` to `/insights/<slug>/`
2. Add a list entry on `/insights/index.html`
3. Optionally feature it on the homepage
4. Add the URL to `sitemap.xml`
5. Set robots meta to `index, follow`
